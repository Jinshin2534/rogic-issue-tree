イシューツリー

キーボードだけで、イシューツリー・ロジックツリーを素早く作れる Mac アプリ。気になるサブイシューは「深掘り」して、新しいツリーとして分け直せます。

Mac 版をダウンロード
無料 · macOS 14 以降 · Apple Silicon / Intel

できること

キーボードだけで作れる

Enter で兄弟、Tab で子を追加。打ち始めればそのまま入力できます。日本語入力にも対応。

サブイシューを深掘り

ノードを選んで ⌘↓ を押すと、それをトップにした新しいツリーが開きます。元のツリーとはリンクでつながります。

ロジックで分解できる

イシュー / Why（原因）/ How（打ち手）/ What（要素）の4種類から選べます。列の見出しや入力の例も、種類に合わせて変わります。

考え方ガイド付き

MECE、切り口のパターン、Why / How / What ツリーの作り方などを、アプリの中でいつでも読めます。例からツリーを作ることもできます。

書き出しも簡単

PNG 画像や Markdown で書き出せます。インデント付きのテキストを貼り付けて、ツリーにすることもできます。

赤字で重要な論点を示す

⌘R で赤字にして、どこに時間を使うかひと目でわかるようにします。

自動保存

1つのファイルに、元のツリーと深掘りしたツリーをまとめて保存します。

インストール

  1. 上のボタンから zip をダウンロードして開きます。
  2. 出てきた「イシューツリー.app」を「アプリケーション」フォルダへ移します。
  3. 初回は「開けません」と表示されることがあります。App Store 外の個人配布アプリで、Apple の公証を受けていないためです。「システム設定 › プライバシーとセキュリティ」を開き、下のほうにある「このまま開く」を押してください。

うまく開けない場合は、ターミナルで次を実行してから開き直してください。

xattr -dr com.apple.quarantine "/Applications/イシューツリー.app"
