# イシューツリー（macOS ネイティブ）設計

## 目的
イシューツリー / ロジックツリーをキーボード中心で素早く作れる macOS アプリ。
出てきたサブイシューを「新しいツリーのトップ」として深掘りし、元ノードとリンクで行き来できる。

## 技術
- SwiftUI + AppKit、macOS 14 以上
- Swift Package（`IssueTreeCore` ライブラリ + `IssueTree` 実行ターゲット + テスト）
- `scripts/build-app.sh` で `.app` バンドルを生成（Info.plist に `.issuetree` 書類型を宣言）

## データモデル（IssueTreeCore）
- `IssueDocument { trees: [Tree] }` … 1ファイル = JSON（拡張子 `.issuetree`）
- `Tree { id, root: Node, parentLink: NodeRef? }`（`parentLink` = 深掘り元のツリーIDとノードID）
- `Node { id, text, isRed, children: [Node], drillTreeID: UUID? }`
- 操作: 兄弟追加 / 子追加 / 階層上げ（outdent）/ 階層下げ（indent）/ 上下入替 / 削除 / 赤字切替 / 深掘り作成
- 深掘り: ノードの `drillTreeID` が無ければ、そのテキストをトップにした新ツリーを作成しリンク。有ればそのツリーを開く。
- 深掘りツリー削除時は元ノードの `drillTreeID` を解除。元ノード削除時、深掘りツリーは残し `parentLink` を解除。

## レイアウト
- 横展開：列 = 階層（トップイシュー, 1層目, 2層目…）、列ヘッダー付き
- 葉ノードを上から順に積み、親は子の縦中央に配置。ノード幅固定（240pt）、高さはテキスト折返しで可変
- 親の右端 → 縦線 → 各子の左端へカギ線で接続
- レイアウト計算は純粋関数（テキスト高さ計測を注入）としてテスト可能にする

## 画面
- 左サイドバー: ツリー一覧（深掘り関係をインデントで表示）
- 中央: ツリーキャンバス（スクロール可）
- ツールバー: ショートカットヒント、PNG / Markdown 書き出し、Markdown 読み込み
- 深掘りツリーのトップ上部に「← 元ツリー: ○○」、深掘り済みノードに ⤴ バッジ（クリックで移動）

## 操作
| キー | 動作 |
|---|---|
| Enter | 兄弟を下に追加（トップでは子を追加）して編集 |
| Tab | 子を追加して編集 |
| ⇧Tab | 階層を上げる |
| ⌥↑ / ⌥↓ | 兄弟内で入替 |
| ↑↓←→ | 選択移動 |
| 文字入力 / Space / ダブルクリック | 編集開始 |
| 編集中 Enter / Esc | 確定（IME変換中の Enter は確定扱いにしない）|
| ⌫ | 選択ノード削除（子ごと）|
| ⌘R | 赤字切替 |
| ⌘↓ | 深掘り（作成 or 移動）|
| ⌘↑ | 元ツリーへ戻る |
| ⌘Z / ⇧⌘Z | 取り消し / やり直し |

## 入出力
- 保存: `DocumentGroup` による `.issuetree`（自動保存）
- 書き出し: PNG（現在のツリー）、Markdown（全ツリー。深掘りツリーは見出しで区切る。インデント2スペースの箇条書き、赤字は `**太字**`）
- 読み込み: Markdown / インデント付きテキストを貼り付け or ファイルから、新ツリーとして生成
- Excel はスコープ外

## テスト
- `swift test`: モデル操作、深掘り作成/削除時のリンク整合、Markdown 往復、レイアウト座標
- UI は手動確認
